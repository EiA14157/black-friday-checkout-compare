# 블프 실결제 비교기

같은 상품을 파는 두 쇼핑몰에 대해 **상품가 − 쿠폰 할인 + 배송비 + 추가 멤버십 비용**을 계산합니다. 가격을 조회·자동 수집하지 않으며 계정, 백엔드, 외부 API, 광고가 없습니다. 입력값은 저장하지 않고 현재 페이지에서만 계산합니다.

- 쿠폰은 정액 또는 정률(소수 둘째 자리까지) 중 하나를 선택합니다.
- 정률 쿠폰의 원 미만 금액은 버립니다. 최대 할인액이 있는 경우 이를 넘지 않습니다.
- 할인액은 상품가를 넘지 않습니다. 배송비·추가 멤버십 비용은 쿠폰 적용 후 별도로 더합니다.
- 이미 가입했다면 추가 멤버십 비용을 비워 두세요. 이번 결제에 실제 필요한 추가 비용만 적습니다.
- 결제 단계의 숨은 조건, 최소 주문금액, 적립·청구 할인은 자동으로 반영하지 않습니다. 입력한 금액과 쇼핑몰 결제 화면을 대조하세요.

## 실행

필요한 HTML, CSS, JavaScript를 `index.html` 하나에 담았습니다. 별도 빌드가 없습니다. GitHub Pages는 기본 브랜치의 루트를 배포하면 됩니다. 로컬에서는 `python3 -m http.server 8000`으로 실행하고 브라우저에서 `http://localhost:8000`을 엽니다.
